ENRG Protocol Whitepaper

A decentralized protocol for tokenizing real-world energy production data on the Solana blockchain.

Abstract

ENRG Protocol enables owners of renewable energy devices — solar panels, wind turbines, hydroelectric generators — to tokenize their verified energy output as SRC (Solar Renewable Certificate) tokens on the Solana blockchain.

Each SRC token represents exactly 1 MWh of verified energy production. The protocol leverages a decentralized oracle network for data verification, Ed25519 cryptographic signatures for device authentication, and Solana's SPL Token standard for on-chain representation.

Max Supply: 1,000,000,000 SRC  ·  1 SRC = 1 MWh of verified energy  ·  Network: Solana

Problem Statement

The global renewable energy market suffers from three critical inefficiencies:

  1. Opaque certification. Renewable Energy Certificates (RECs) are issued by centralized bodies with limited auditability, slow issuance cycles, and high administrative overhead.
  2. Fragmented markets. Energy producers in different regions cannot access unified, liquid markets for their certificates. Small producers are effectively excluded.
  3. Verification trust gap. Buyers of RECs must trust intermediaries rather than cryptographic proof. Double-counting and fraudulent certificates are persistent problems.

Solution

ENRG Protocol replaces centralized certification with a trustless, on-chain flow:

1
Device Registration

Owners register devices on-chain via the enrg-profile program. Each device receives a unique Program Derived Address (PDA).

2
Oracle Verification

The ENRG Oracle network reads device telemetry and signs energy production data using Ed25519 keys. The signature is verified on-chain by the enrg-mvp program.

3
On-Chain Minting

Upon successful verification, the program mints the corresponding amount of SRC tokens directly to the device owner's wallet via CPI to the SPL Token program.

4
Immutable Record

Every mint event is recorded on-chain. The full audit trail is publicly verifiable via Solana Explorer.

Protocol Design

The protocol consists of two Solana programs deployed on-chain:

enrg-mvp

The core minting program. Accepts oracle-signed energy data, verifies the Ed25519 signature via Solana's native ed25519_program, and calls the SPL Token program via CPI to mint the corresponding SRC amount.

enrg-profile

Manages participant and device registration. Each profile and device is stored as a PDA. The profile program handles Create/Update/Close lifecycle for both participants and devices.

Oracle System

The ENRG Oracle is a permissioned off-chain service that:

  • Ingests device telemetry over HTTPS/MQTT
  • Validates device registration status on-chain
  • Aggregates energy readings over configurable time windows
  • Signs batched mint requests with its Ed25519 keypair
  • Submits signed instructions to the enrg-mvp program

The oracle's public key is embedded in the on-chain program at deployment. Future versions will support a multi-oracle quorum model to eliminate the single point of trust.

Governance

ENRG Protocol v1 is governed by the founding team. A DAO governance model is planned for v2, where SRC token holders will be able to vote on:

  • Approved device categories and verification standards
  • Oracle operator set and quorum thresholds
  • Protocol fee parameters
  • Treasury allocation
