How It Works

A modern DePIN onboarding path for energy producers, powered by verified IoT data and Solana minting.

⚡

Connect Your Source

Register your solar panel, wind turbine, or hydro generator. Each device gets a unique Ed25519 key pair stored in Secure Element (ATECC608).

🔗

Verify & Mint

IoT device signs energy readings every 10 minutes. Oracle verifies Ed25519 signature, validates nonce + timestamp, and mints SRC tokens via Solana smart contract.

💰

Earn & Trade

85% of minted SRC goes to you. Stake tokens, earn protocol fees, and participate in DAO governance. 1 SRC = 1 MWh of verified energy.

Architecture

Two-Program Architecture on Solana — Modular, Auditable, Upgradeable.

🧱

enrg-mvp — Core Protocol

Handles minting, proof verification (Ed25519 via sysvar), vault management, staking, buyback & burn, vesting, and device lifecycle. The central engine of the protocol.

📋

enrg-profile — Device Profiles

Manages energy producer profiles with rated power, device metadata, and 30-day rolling energy window. Accessed by enrg-mvp via CPI using declare_program!.

🔄

CPI Integration

enrg-mvp calls enrg_profile::cpi::record_production during each mint to update the producer's energy profile. The profile's rated_power determines the max energy per mint.

Security Model

Multi-layer protection from device to blockchain. Based on ENRG Security Policy and STRIDE threat model.

🔐 Ed25519 Verification

All device signatures are verified on-chain via Solana sysvar instructions. The private key never leaves the device — stored in ATECC608 Secure Element.

🛡️ Replay Protection

Every proof includes a monotonic nonce and timestamp. MAX_PROOF_AGE = 1 hour. Duplicate nonces are rejected on-chain.

⚡ Rate Limiting

Oracle API enforces rate limits: 200 req/min general, 100 req/min for proof submission, 20 req/min for device registration.

📋 STRIDE Threat Model

Spoofing → Ed25519 · Tampering → Signed packets · Repudiation → Nonce + timestamp · DoS → Gas limits · Elevation → PDA architecture

🔍 Anomaly Detection

Energy Reputation Score (ERS) tracks device history. Sudden spikes, night-time generation, and profile anomalies trigger quarantine.

🏛️ Multi-Oracle (Future)

Planned transition to Switchboard decentralized oracle network for redundant verification and fault tolerance.
